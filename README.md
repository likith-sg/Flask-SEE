## 🎯 Overview
Flask-SEE is a car rental booking system built with Flask, a micro web framework for Python. It provides a simple and intuitive way for users to book cars and for administrators to manage bookings. The system consists of a user interface where users can select a car, provide their details, and book the car for a specified number of hours.

The system is designed to solve the problem of manual car rental booking systems, which can be time-consuming and prone to errors. With Flask-SEE, users can book cars online, and administrators can easily manage bookings and track rental hours.

Flask-SEE is suitable for car rental companies, driving schools, and other organizations that need to manage car bookings.

## ✨ Features
- 🔥 **User Registration** — allows users to provide their details, including name, age, email, phone number, and license.
- 🚗 **Car Selection** — enables users to select a car model and view its price per hour.
- 📅 **Booking Management** — allows administrators to manage bookings, including viewing booking details and tracking rental hours.
- 💸 **Rental Hour Calculation** — automatically calculates the total cost of the rental based on the number of hours booked.
- 📝 **License Upload** — allows users to upload their license documents.
- 📊 **Database Integration** — stores booking data in a SQLite database.
- 🚨 **Error Handling** — displays error messages to users if required fields are not filled or if there are any issues with the booking process.
- 📣 **Flash Messages** — displays flash messages to users after a successful booking or if there are any errors.

## 🚀 Getting Started

### Prerequisites
Python 3.x, Flask, Gunicorn, and SQLite are required to run Flask-SEE.

### Installation
```bash
pip install flask gunicorn
```

### Quick Start
```bash
gunicorn app:app
```

## 📖 Usage
1. Open a web browser and navigate to `http://localhost:8000` to access the Flask-SEE user interface.
2. Select a car model and click on the "Book" button to proceed with the booking process.
3. Fill in the required fields, including name, age, email, phone number, and license, and upload your license document.
4. Specify the number of hours you want to rent the car and click on the "Book" button to complete the booking process.
